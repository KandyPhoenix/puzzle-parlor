Questions

Does it work offline?

Yes. Once the app has loaded, puzzles play without a connection. The code check and progress sync need a connection, but a puzzle you have already opened keeps working.

Which devices?

Any modern browser: iPad, iPhone, Android tablets and phones, Windows and Mac. Puzzles of 400 pieces and up are best on a tablet or computer screen.

I lost my code.

Can I move the code to a new device?
